# Storage Layout

## Mounts

- `/media/tusa/Data` - application data, Docker configs, downloads, photos, ROMs
- `/media/tusa/Media` - movies, TV, music, books, comics, audiobooks
- `/media/tusa/Storage` - projects, archives, 3D files, backups

## Drives

- Data: 22TB ext4
- Media: 11TB ext4
- Storage: 13TB ext4

## Rule

Do not use `Data1` or `Media1`. Those were accidental auto-mount paths and should not be used.
