# Homeland

Homeland is my self-hosted command center for managing my homelab, media servers, AI infrastructure, and game development environment.

## Current Features

- Docker Mission Control
- Ubuntu Server Monitoring
- Windows Monitoring
- Synology Monitoring
- Storage Monitoring
- Global Dashboard

## Planned Features

- AI Center (Ollama / ComfyUI)
- Jellyfin Dashboard
- Immich Dashboard
- Arena Aeternum Development Tracker
- Remote Administration
- Backup Management
- Network Monitoring
- Collections Management

## Technology

- Flask
- Docker
- Python
- Prometheus
- Windows Exporter
- Synology APIs

## Installation

```bash
docker compose up -d --build
```

Then browse to:

```
http://SERVER_IP:8088
```
